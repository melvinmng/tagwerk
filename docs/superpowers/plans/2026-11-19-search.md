# Suche nach Terminen und Aufgaben – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Status:** Entwurf vom 19.11.2026 zum freigegebenen Spec. Nichts gebaut, nichts am Gerät oder im Simulator geprüft. Der Ist-Zustand stammt aus dem Quelltext (Stand `c42f055`); alle Aussagen zu EventKit und GitHub außerhalb des Quelltexts sind Annahmen des Specs und werden in Task 1 geprüft.

**Goal:** Ein Suchblatt, erreichbar über eine Lupe in „Planen“ und „Aufgaben“, findet Termine, offene und erledigte Aufgaben, Notizen und Einkaufsartikel ohne Netz, sucht auf Tipp zusätzlich bei GitHub und stellt denselben Suchkern dem Assistenten als lesendes Werkzeug `search` bereit.

**Architecture:** Filtern bei Bedarf (Spec §4, Ansatz A): Quellen laden, im Speicher filtern, beim Schließen verwerfen. Der Suchkern ist reine Logik in `TagwerkCore/Search/`; Termine liest ein eigener `actor` mit nur lesendem `EKEventStore` in `RemindersKit`; ein `SearchModel` (`@Observable`, `@MainActor`) hält den Zustand des Blatts und bekommt alle Quellen als Closures (`SearchSources`), damit es ohne EventKit, Netz und Phase-5-Typen testbar ist. Kein neues SwiftData-Modell, keine neue Einstellung.

**Tech Stack:** Swift 6, SwiftUI (iOS 27), SwiftData, EventKit, Swift Testing; lokale Pakete `TagwerkCore`, `RemindersKit`, `GitHubKit`; XcodeGen (`app/project.yml`).

**Spec:** `docs/superpowers/specs/2026-11-19-search-design.md` (maßgeblich; Mockup `docs/superpowers/mockups/2026-11-19-search-mockups.html`). Abhängigkeit: `docs/superpowers/specs/2026-11-19-phase-5-shopping-notes-design.md`.

## Review Focus

Eingaben und Zustände, die das Spec nicht nennt, die einen Nutzer aber treffen. Jede Zeile hat ihren Test im genannten Task.

1. **Suchwort mit Sonderzeichen** („c++“, „(“, „#“, „#abc“, „a.b“): wird als gewöhnliche Teilzeichenkette gesucht, nie als Muster; „#abc“ ist Text, keine Issue-Nummer. → Task 2, `specialCharactersAreSearchedLiterally`.
2. **Faltung ändert die Länge** („Straße“ gesucht mit „strasse“, Zeichen voller Breite, kombinierende Akzente, Emoji im Titel): Die Fundstellen sind gültige Bereiche der **ursprünglichen** Zeichenkette, die Hinterlegung stürzt nicht ab und trifft „Straße“ ganz. → Task 2, `highlightRangesAreValidInOriginalString`.
3. **Schnelles Tippen bei laufendem Terminabruf:** Das Ergebnis eines früheren Suchworts überschreibt nie das aktuelle; kommt der Abruf nach dem Schließen an, ändert er nichts. → Task 5, `lateEventLoadNeverOverwritesNewerQuery`.
4. **Zusammengeführter oder mehrtägiger Termin beim Öffnen:** Ein Treffer, dessen Vertreter im Tagesabruf in einem anderen Kalender liegt (`mergedCalendarIDs`) oder der vor dem Tag begonnen hat, wird trotzdem aufgelöst und nicht als „geändert“ gemeldet. → Task 8, `resolveFindsMergedAndMultiDayEvents`.
5. **Suchwort mit Anführungszeichen oder Qualifizierern in der Online-Suche** (`"offen`, `repo:x/y`): Der Text reist als GraphQL-Variable, wird nie in das Dokument eingesetzt, und ein Fehler von GitHub zeigt die allgemeine Fehlermeldung statt eines Absturzes. → Task 9, `searchTextTravelsAsVariable`.

```swift
public enum SearchText {
    /// Case-, diacritic- and width-insensitive form; "ß" becomes "ss". "ue" stays "ue".
    public static func fold(_ text: String) -> String
    /// Ranges of `foldedWord` in `text`, expressed in indices of the original `text`.
    public static func ranges(of foldedWord: String, in text: String) -> [Range<String.Index>]
}
public enum SearchField: String, Sendable, Hashable {
    case title, notes, location, calendar, container, project, label, issueNumber, kind, quantity
}
public struct SearchDocument: Sendable {
    public init(event: CalendarEvent, calendarName: String?)
    public init(task: TaskItem)                               // issue number from task.url?.lastPathComponent
    public init(noteText: String, kindLabel: String)          // title = first line of the text
    public init(shoppingName: String, quantity: String?)
}
public struct SearchQuery: Sendable, Equatable {
    public static let minimumLength = 2
    public init?(_ raw: String)                               // nil below two characters after trimming
    public func match(_ document: SearchDocument) -> SearchMatch?
}
public struct SearchMatch: Sendable, Equatable {
    public let titleRanges: [Range<String.Index>]
    public let snippet: Snippet?                              // only when no word hits the title
    public let matchedFields: [SearchField]                   // in SearchField declaration order
    public struct Snippet: Sendable, Equatable { public let field: SearchField; public let text: String; public let ranges: [Range<String.Index>] }
}
```
